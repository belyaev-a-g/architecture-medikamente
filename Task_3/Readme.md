## Задание 3. Оценка Data Encryption at Rest and In Transit

| Категория данных | Состояние | Уровень конфиденциальности | Основание для защиты | Применяемые меры |
|------------------|-----------|----------------------------|----------------------|------------------|
| Данные пациентов | В состоянии покоя (хранение) | Персональные данные | Предотвращение компрометации и утраты | Сведение к необходимому минимуму, дисковое шифрование, контроль доступа к базам данных, ведение аудита, создание резервных копий |
| Медицинская информация | В состоянии покоя (хранение) | Медицинская тайна | Предотвращение компрометации и утраты | Сведение к минимуму, шифрование на уровне файловой системы, ограничение доступа к БД, логирование действий, бэкапирование |
| Медицинская информация | В процессе передачи | Медицинская тайна | Защита от перехвата | Шифрование каналов связи |
| Операционные сведения (записи на приём, услуги, складские операции) | В состоянии покоя (хранение) | Внутренние служебные данные | Защита от утечек и потерь | Шифрование на уровне ФС, разграничение доступа к БД, аудит, резервное копирование |
| Операционные сведения (записи на приём, услуги, складские операции) | В процессе обработки | Внутренние служебные данные | Исключение утечки | Обезличивание |
| Платёжные операции | В процессе передачи | Конфиденциальные сведения | Предотвращение перехвата | Обфускация (маскирование данных) |
| Данные сотрудников | В состоянии покоя (хранение) | Персональные данные | Защита от утечек и потерь | Минимизация, шифрование ФС, контроль доступа к БД, аудит, бэкапы |
| Зарплатные данные сотрудников | В процессе обработки | Персональные данные | Исключение утечки | Обезличивание |
| Учётные записи и пароли сотрудников | Хранение и передача | Конфиденциальная информация | Защита от компрометации и потери | Шифрование базы NTDS на уровне ОС, ограничение доступа, шифрование дисков, резервный контроллер домена, защищённые протоколы, использование VPN |

Средства реализации защитных мер:

| Метод защиты | Применяемый инструмент                                                                                                            | Дополнительные сведения |
|--------------|-----------------------------------------------------------------------------------------------------------------------------------|-------------------------|
| Минимизация данных | Отсутствует как продукт                                                                                                           | Осуществляется вручную на стадии архитектурного проектирования |
| Шифрование на уровне ФС | BitLocker                                                                                                                         | Штатное средство Windows Server |
| Разграничение доступа к БД | Средства NTFS, Active Directory, межсетевой экран, ролевая модель внутри СУБД                                                     | Встроенный функционал Windows Server |
| Аудит действий | Имеется в CRM и «1С»                                                                                                              | При разработке собственной CRM потребуется доработка этого функционала |
| Резервное копирование БД | Встроенные средства СУБД\ специализированные скрипты                                                                              | — |
| Бэкапирование файлов | Veeam Backup\Bacula                                                                                                               | Один из вариантов; наиболее насыщен по функциям, но возможны бесплатные аналоги или собственные скрипты |
| Обезличивание данных | PostgreSQL Anonymizer                                                                                                             | Один из вариантов; существуют также платные продукты (например, Redgate Data Masker, Attacama One) либо реализация силами разработки |
| Обфускация данных | Стандартный механизм «Скрытие конфиденциальной информации»                                                                        | Для систем на платформе «1С» |
| Защита учётных данных пользователей домена | Шифрование хранилища NTDS на уровне ОС, ограничение доступа, дисковое шифрование, резервный контроллер, защищённые протоколы, VPN | Встроенный функционал Windows Server |

Дополнительные технические решения:

| Способ защиты | Инструмент | Особенности применения |
|---------------|------------|-------------------------|
| Шифрование данных в БД на уровне хранения | pgcrypto (PostgreSQL) | Поддерживает шифрование отдельных столбцов, хэширование паролей |
| Маскирование данных на уровне БД | pgcrypto (PostgreSQL) | Функция gen_random_bytes для генерации криптостойких случайных значений |
| Шифрование при передаче | HTTPS (TLS 1.3) | Применяется для всех каналов обмена информацией |
| Шифрование на уровне приложений | ALE (Application-level encryption) с алгоритмом AES-256 | — |
| Шифрование токенов доступа | JWE (JSON Web Encryption) | — |
